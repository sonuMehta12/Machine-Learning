# Phase 2 — Deep Learning Foundations (PyTorch, From Scratch)

Weeks 10–19. Write a training loop by hand before touching any high-level trainer.

Projects to build here:
1. **micrograd, from memory** — rebuild the autograd engine a week after Karpathy's video, without rewatching
2. **MNIST/FashionMNIST from raw PyTorch** — no shortcuts; write Dataset, DataLoader, model, training loop, validation loop
3. **Pet classifier, twice** — CNN from scratch on Oxford-IIIT Pets, then fine-tuned ResNet-50/EfficientNet — compare
4. **Custom dataset, end to end** — collect, label, split, train your own small image dataset

Done when: you can write a complete PyTorch training loop from a blank file, without reference, and diagnose a loss curve on sight.
