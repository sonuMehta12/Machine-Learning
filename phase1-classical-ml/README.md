# Phase 1 — Classical ML and the Data Stack

Weeks 2–9. Scikit-learn, the full supervised learning workflow, data leakage, imbalanced classification.

Projects to build here:
1. **Tabular baseline** — EDA → cleaning → feature engineering → 3 models compared → tuning → held-out evaluation
2. **Deliberately break it** — introduce data leakage on purpose, observe the score lie, then fix it
3. **Imbalanced classification** — a rare-positive-class dataset (fraud/defect-style), PR-AUC, threshold tuning

Done when: given any CSV and a target column, you can produce a defensible model with an honest error analysis in an afternoon.

See the "Phase 1" section of [ROADMAP.md](../ROADMAP.md) for resources and detail.
